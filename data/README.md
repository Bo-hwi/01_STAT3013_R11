# Data sources and provenance

This folder documents where every input file comes from, how it was obtained and how to verify it. Raw data files are **not** committed to Git (see `.gitignore`); only this documentation and lightweight `.gitkeep` markers are versioned.

## 1. Sources and licenses

| Source | Link | License / terms | Retrieved |
|---|---|---|---|
| Corporación Favorita — Store Sales (Kaggle) | https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data | Kaggle competition rules; redistribution not allowed | 21/10/2026 (team copy on Google Drive) |
| Open-Meteo Historical Weather API (ERA5 reanalysis) | https://open-meteo.com/en/docs/historical-weather-api | CC BY 4.0 — attribution required | 21/10/2026 |

Raw files are kept out of the repository for two reasons: `train.csv` alone is about 122 MB, and the Kaggle competition rules do not permit public redistribution. Each member downloads the files locally and verifies them against the hashes in section 3.

**Weather caveat:** ERA5 is a reanalysis product published with a delay. Weather values for day *t* may not have been available at the forecast origin (end of day *t−1*). Any model using these variables is a *retrospective weather-aware* experiment, not an operational backtest.

## 4. How to reproduce

1. **Favorita:** open the Kaggle link above, accept the competition rules, click *Download All*, unzip and place the 7 CSV files in `data/raw/favorita/`. Alternatively copy them from the team Drive folder `1. Favorita raw`.
2. **Weather:** currently copied from the team Drive folders `2. Weather raw`, `3. Geographic data` and `4. Processed data` (downloaded on 21/10/2026). A re-download script will be provided in `src/data/fetch_weather.py` (in progress); until then, the Drive copy is the reference version.
3. Run `python scripts/build_source_catalog.py` and check that every SHA-256 matches section 3. A mismatch means the local file differs from the version used in the analysis.
4. Run `python scripts/qa_quick_checks.py` to reproduce the initial QA findings in `docs/data_quality_report.md`.

## 5. Notes

- **Environment:** Python 3.14 (Windows), packages from `requirements.txt`. The project README recommends Python 3.11; versions will be pinned before the final experiments.
- `test.csv` and `sample_submission.csv` belong to the Kaggle competition and contain no sales labels. They are **not** used as a labelled test set; all evaluation uses time-based folds inside `train.csv`.
- `train.csv` has no rows for 25 December of 2013–2016 (stores closed). Missing days are **not** filled with zero. See `docs/data_quality_report.md`, QA-01.
- Weather is a city-level grid-cell value, not a store-level measurement; two nearby cities may share the same ERA5 grid cell.
